# Smart Expense Analyzer

A beginner-friendly Python project that helps users track expenses
and monitor their budget.

## Features
- Budget input validation
- Expense entry with category names
- Category-wise expense totals
- Highest-spending category detection
- Budget warnings
- Individual expenditure history
- JSON file storage

## Technologies Used
- Python
- JSON
- File handling
- Dictionaries and lists
- Exception handling

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

   python main.py
